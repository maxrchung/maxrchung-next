REAL GAMBLING is a slot machine game and a sequel to [REAL
FISHING](https://maxrchung.com/projects/realfishing). You pay money to pull the
slot machine or upgrade your reels (slot machine columns). But be careful, if
you can't pay the slot machine, you'll pay with your fingers.

This game combines both 2D UI and 3D elements. I worked on a variety of
different parts including the hand, lever, number font, reel animation, UI layout, and end
screens. This is the first time I think I've done some image texturing so that's
pretty cool. Overall a pretty fun experience but definitely an exhausting
last day as we had to mega crunch to get a working game together.

Made over MLK 2026 3-day game jam.
